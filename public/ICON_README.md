# Instructions pour créer les icônes PWA

Les fichiers `icon-192x192.png` et `icon-512x512.png` sont nécessaires pour le PWA.

## Option 1 : Utiliser un outil en ligne (Recommandé)

1. Allez sur https://realfavicongenerator.net/
2. Uploadez votre logo OFARO TECH
3. Téléchargez les icônes générées
4. Remplacez les fichiers dans `/public/`

## Option 2 : Utiliser Canva (Gratuit)

1. Créez un design 512x512px sur https://www.canva.com
2. Fond orange (#FF6B00)
3. Texte "OT" en blanc, centré, gros et bold
4. Téléchargez en PNG
5. Redimensionnez à 192x192 pour la petite version

## Option 3 : Figma / Photoshop

Créez deux carrés :
- 192x192px pour `icon-192x192.png`
- 512x512px pour `icon-512x512.png`

**Spécifications** :
- Fond : #FF6B00 (Orange OFARO TECH)
- Texte : "OT" en blanc (#FFFFFF)
- Police : Arial ou Inter, Bold
- Centré verticalement et horizontalement

## Fichiers temporaires actuels

Les fichiers placeholders actuels fonctionnent mais ne sont pas optimaux.
Remplacez-les dès que possible avec de vraies icônes pour une meilleure qualité.
