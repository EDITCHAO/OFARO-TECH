🔧 PERSONNALISATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Pour changer les couleurs :
  1. Ouvrez le fichier .svg
  2. Cherchez fill="#..." ou stroke="#..."
  3. Changez la couleur

Pour remplacer par une photo :
  1. Optimisez votre image (TinyPNG)
  2. Remplacez le fichier .svg
  3. Redémarrez : npm run dev
