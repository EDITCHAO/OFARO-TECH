Le client trouvait que les cadres des images étaient trop grands sur la page 
/secteurs. Les modifications visent à réduire la taille des images et à 
compacter le contenu pour un meilleur équilibre visuel.

┌──────────────────────────────────────────────────────────────────────────────┐
│ ✅ MODIFICATIONS EFFECTUÉES                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

1. IMAGES RÉDUITES
   • Format: aspect-square (1:1) → aspect-[4/3] (rectangulaire)
   • Réduction: ~25% en hauteur
   • Padding titre: p-8 → p-6
   • Taille icône: text-6xl → text-5xl
   • Taille titre: text-3xl → text-2xl

2. BADGE TITRE (Banques & Finances, etc.)
   • Marge: mb-6 → mb-4 (-33%)

3. DESCRIPTION PRINCIPALE
   • Marge: mb-6 → mb-4 (-33%)
   • Taille: normale → text-sm

4. SECTION "SERVICES PROPOSÉS"
   • Marge: mb-6 → mb-4 (-33%)
   • Titre: normale → text-sm
   • Icône titre: normale → text-xs
   • Espacement items: gap-3 → gap-2
   • Taille items: text-sm → text-xs
   • Points: w-2 h-2 → w-1.5 h-1.5

5. CADRES "DÉFIS" ET "SOLUTIONS"
   • Espacement: space-y-3 → space-y-2 (-33%)
   • Bordure: border-l-4 → border-l-3
   • Padding: p-3 → p-2.5
   • Titre: text-sm → text-xs
   • Texte: text-sm → text-xs

┌──────────────────────────────────────────────────────────────────────────────┐
