## 🛠️ Optimisation des images

### Avant d'ajouter les images :

1. **Redimensionner** selon les dimensions recommandées
2. **Optimiser** le poids des fichiers

### Outils d'optimisation :

**En ligne (gratuit)** :
- https://tinypng.com/ (réduit jusqu'à 70% le poids)
- https://squoosh.app/ (contrôle avancé)
- https://compressor.io/

**Objectif** : Poids < 200KB par image
